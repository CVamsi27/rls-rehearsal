# Independent pilot brief

Give the pilot the release link, the README, and this task. Ask them to start from a clean checkout without you driving.

1. Start the Compose app and create a work item with the first demo key.
2. Close it and check the history. Switch keys and look for the first workspace’s item.
3. Run the proof and the broken control. Explain in your own words why both should succeed.
4. Rename the synthetic workspaces in the fixture, rebuild, and rerun the proof. Report any step that required guessing or clarification.

Capture the candidate commit, OS, Docker and Node versions, time to first successful task, completion of each step, and the first blocker or confusing instruction. Ask whether they would try the pattern on a disposable copy of their own schema. Report a completed walkthrough as external validation. Report adoption only once someone uses it in their workflow.

Pilot status for the local candidates is **pending**.
